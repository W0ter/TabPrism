# TabPrism

Color-code and style your Obsidian workspace tabs and folder hierarchy dynamically based on note folder paths! TabPrism helps you visually organize your workspace by instantly applying customizable color themes to your files and folders.

## ✨ Features

- **🎨 Color-Coded Tabs**: Assign distinct colors to your tabs based on the folder path they belong to.
- **📂 File Explorer Sync**: Mirror your custom colors directly onto the sidebar's folder titles and icons. Choose between a bold **Background Fill** or subtle **Text Tinting**.
- **⚙️ Granular Styling**: Have complete control over what gets colored. Toggle color applications for Tab Backgrounds, Borders, Text, and Icons independently.
- **📝 Custom Text Colors**: Need high contrast for readability? Override text and icon colors independently from the background accent.
- **📌 Pinned Tab Indicators**: Never lose track of your pinned tabs. Make them stand out with customizable indicators like **Accent Dots**, **Underlines**, or **Full Fills**.
- **🛠️ Flexible Rule Management**: Easily collapse, reorder, and toggle individual folder rules on the fly without losing your settings.

## 🚀 Installation

Currently, TabPrism can be installed manually or effortlessly via [BRAT](https://github.com/TfTHacker/obsidian42-brat).

### Using BRAT (Recommended)
1. Install the **BRAT** plugin from the Obsidian Community Plugins tab and enable it.
2. Go to Options > BRAT > **Add a beta plugin for testing**.
3. Paste this repository URL: `https://github.com/W0ter/TabPrism`
4. Click **Add Plugin**.
5. Enable **TabPrism** in your Community Plugins list!

### Manual Installation
1. Download `main.js` and `manifest.json` from the root of this repository.
2. Create a folder named `TabPrism` in your vault's `.obsidian/plugins/` directory.
3. Place the downloaded files into the `TabPrism` folder.
4. Reload Obsidian and enable TabPrism in the Community Plugins list.
